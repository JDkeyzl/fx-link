# 02 Brand ask scripts — 缺件号时按品牌追问

> 原则：缺件号时优先要 **OEM 照片 / 原厂件号**；车型字段用于缩小检索，不能代替件号。  
> `[待确认]` = 现场销售实际还问哪些字段。

## Common (all brands)

1. Exact part number if available (paste as on the box / invoice).
2. If unknown: clear photo of old part (casting number / sticker) + vehicle model / chassis plate.
3. Qty and destination / Incoterm preference.

## SINOTRUK / HOWO

- Part numbers often start with **WG** or **AZ** (company convention).
- Ask: truck series (HOWO / HOWO-A7 / etc.), engine family if engine parts, axle if chassis parts.
- `[待确认：你们对外最常用的车型称呼表]`
- 中文追问示例：「有件号吗？没有的话请发旧件照片和车型/铭牌。」

## SHACMAN

- Ask: model (e.g. F3000 / X3000 — `[待确认：实际主销系列]`), cab year if known, system (brake / gearbox / electrics).
- Prefer OEM number on packing list over aftermarket aliases.

## WEICHAI

- Ask: engine model (WP10 / WP12 / … `[待确认]`), application (truck / generator / construction), whether assembly or single spare.
- Engine parts without engine model → do not guess; request nameplate photo.

## Other brands in catalogue (FAW etc.)

- Same pattern: brand + part_no or photo; do not invent cross-reference without tool hit.
- `[待确认：目录外品牌是否一律转人工]`

## When search returns many hits

- Show top candidates from tools; ask customer to confirm part_no before adding to quote draft.
- Never pick “the cheapest” automatically for safety-related categories. `[待确认：哪些品类禁止自动选最低价]`
