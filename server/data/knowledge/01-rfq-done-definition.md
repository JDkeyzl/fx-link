# 01 RFQ done definition — 需求卡完成定义（何时可进报价草稿）

> Desk 在字段未达标时应继续追问，而不是假装已可正式报价。  
> `[待确认]` 处请销售按真实作业习惯改阈值与必填项。

## Definition of Done — EXW reference draft OK

All of the following should be on the requirement card (or explicitly waived by customer):

1. **Brand** (e.g. SINOTRUK / SHACMAN / WEICHAI) or confirmed multi-brand list.
2. At least one of: **exact part_no** (tool-verified) **OR** vehicle model + photo/OEM drawing when part_no unknown.
3. **Quantity** (pcs) and order type hint: sample / trial / recurring. `[待确认：样品默认起订是否单独政策]`
4. **Destination** country or port (even for EXW — needed for packing advice later).
5. **Incoterm preference** (default assumption: EXW if customer silent). `[待确认：默认是否一律按 EXW]`
6. **Quality preference** if price-sensitive: OE / OEM-quality / economy — must be customer-stated, not assumed.
7. **Contact channel** (WhatsApp / email) before locking any human-confirmed quote. `[待确认：草稿阶段是否强制留联系方式]`

## Not Done — keep collecting

- Only a vague name (“brake pad”) with no brand, no part_no, no vehicle.
- Customer wants “cheapest CIF Lagos tomorrow” with no line items.
- Mixed list in Excel not yet parsed into lines. `[待确认：P3 上线前人工如何接收 Excel]`

## Exit phrases (when Done)

- EN: “I can prepare an **EXW reference line list** from catalogue tools. Sales will confirm MOQ, packing and freight.”
- 中文：「我可以先整理 **EXW 参考行项目**（来自目录工具）。MOQ、包装与运费由销售确认。」

## Exit phrases (when Not Done)

- EN: “To avoid wrong parts, I still need: …”
- 中文：「为避免错件，还需要您补充：…」
